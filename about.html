About Quantum Shift

Quantum Shift is a small educational web app built to demonstrate:

  • Valid HTML5 with semantic structure
  • External CSS and JavaScript (no embedded code)
  • jQuery UI widgets and simple custom plugins
  • AJAX requests for JSON-formatted data
  • Basic accessibility and keyboard navigation

The goal is not to be a huge production game, but to be clear, readable, and easy to maintain. Another student should be able to open this project in an editor and understand what is going on.

Accessibility Notes

  • Headings follow a logical order.
  • Interactive controls are keyboard accessible.
  • Important updates (score, tips) are announced via ARIA live regions.
  • Color is not the only way information is communicated.

If this was a real production project, we would also add focus outlines for custom elements, perform screen reader testing, and run automated accessibility checks.
