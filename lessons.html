JavaScript Basics

  • let and const declare variables.
  • Use === for strict comparisons (type + value).
  • Functions group reusable logic: function greet(name) { ... }
  • console.log() is your best friend while debugging.

CSS Basics

  • Selectors target elements: .class, #id, header, etc.
  • margin controls space outside; padding controls space inside.
  • Flexbox (display: flex;) is great for alignment and layout.
  • Use a small, consistent set of colors and spacing values for cleaner design.

DOM & Events

  • The DOM is the in-memory representation of your HTML.
  • Use document.querySelector() or jQuery's $(...) to find elements.
  • Events (click, keydown, input) let you react to user actions.
  • Always keep your JS in external files for separation of concerns.
