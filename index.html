Quick FAQ

Who is Quantum Shift for?

Quantum Shift is for students who are just getting used to JavaScript and CSS. It also works as a quick review tool before quizzes and exams.

What tech does this project use?

The project uses HTML5, CSS3, Tailwind utility classes, JavaScript, jQuery, jQuery UI, and AJAX with JSON data. All custom CSS and JavaScript live in separate files.

Can I run this inside Eclipse?

Yes. You can import the project as a Dynamic Web Project, place files under WebContent, and run it on a local server. All paths are relative.
