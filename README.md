# Quantum Shift

> A neon‑themed educational web app and quiz game designed to help students learn JavaScript and CSS basics. 

The project is built to be clear, readable, and easy to maintain so that other developers can easily open the code and understand how it works.

---

## 🚀 Features

* **Interactive Quiz Game:** Answer questions correctly to charge up a neon "Quantum Bar" and build a streak[cite: 2, 3].
* **Study Materials:** Includes quick lesson notes covering JavaScript Basics, CSS Basics, and DOM & Events[cite: 4].
* **Interactive UI Components:** Utilizes jQuery UI for interactive tabs, FAQ accordions, and custom tooltips[cite: 3, 4].
* **Asynchronous Data Loading:** Uses AJAX and jQuery's `getJSON()` method to pull additional study tips and fun facts from local JSON files.
* **Built-in Accessibility:** Implements logical heading orders, keyboard-accessible controls, color-independent information, and ARIA live regions to announce score updates to screen readers[cite: 1].

## 💻 Tech Stack

* **Markup & Styling:** Valid HTML5 with semantic structure and external CSS3[cite: 1, 3].
* **CSS Framework:** Tailwind CSS (loaded via CDN) for modern utility classes[cite: 3].
* **Scripting:** Vanilla JavaScript and jQuery (v3.7.1) with logic separated into external files[cite: 1, 3, 4].
* **UI Library:** jQuery UI (v1.13.3) for styling and advanced user interface widgets[cite: 1, 3].

## 📁 Project Structure

* `index.html`: The main landing page featuring a pseudo-sci-fi hero dashboard and interactive FAQ[cite: 3].
* `game.html`: The core quiz application with live scoring and interactive feedback[cite: 2].
* `lessons.html`: An organized study sheet utilizing tabbed navigation to separate topics[cite: 4].
* `about.html`: Contains project goals, accessibility documentation, and a mockup feedback form[cite: 1].

## 🛠️ Getting Started

### Local Setup
Simply clone the repository, open the project folder in your preferred code editor, and run it on a local development server (such as VS Code's Live Server).

### IDE Integration
You can also easily import this into IDEs like Eclipse as a Dynamic Web Project. Just place the files under `WebContent` and run it on a local server.

**Note:** All resource paths for CSS and JavaScript are relative, meaning no complex setup, dependencies, or build steps are required to view and edit the project[cite: 1, 3].
